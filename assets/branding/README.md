# Wiffle Ball Manager icon

`wiffle-ball-manager-icon.png` is the 1024×1024 full-bleed master artwork used to generate the iOS and Android launcher icons.

The artwork intentionally has no baked-in rounded corners; each operating system applies its own icon mask.

Android 8.0 and newer use an adaptive icon resource, allowing the artwork to fill
the launcher mask instead of appearing inside a legacy white compatibility badge.
